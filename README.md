#  BoneAge Pro

BoneAge Pro is a healthcare-inspired **C++ Object-Oriented Programming (OOP)** project that simulates the estimation of skeletal maturity using bone maturity scores from key hand and wrist bones. The application compares the estimated bone age with the patient's chronological age and classifies bone development as **Normal**, **Delayed**, or **Advanced**.

> **Disclaimer:** This project is developed for educational purposes only. It does **not** perform real medical diagnosis and should not be used for clinical decision-making. Actual bone age assessment is performed by qualified healthcare professionals using hand and wrist radiographs and established medical standards such as the Greulich & Pyle Atlas or Tanner-Whitehouse (TW) methods.

## Sample Workflow

1. Register a patient.
2. Enter maturity scores for the Radius, Ulna, Carpals, Metacarpals, and Phalanges.
3. Estimate skeletal age.
4. Compare skeletal age with chronological age.
5. Generate a diagnostic classification.
6. Save the patient's record.
7. View history and statistics.
